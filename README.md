# 🎯 MERN Task Manager

A basic full-stack Task Manager built with MongoDB, Express, React, and Node.js to practice CRUD operations across the MERN stack.

---

## 🚀 Features

- ➕ Add tasks with title & description
- ✅ Mark tasks complete/incomplete
- 🗑️ Delete tasks
- 🔄 Real-time list update via REST API

---

## 🛠️ Tech Stack

- MongoDB
- Express.js
- React
- Node.js

---

## ⚙️ Installation

### Backend
```bash
cd backend
npm install
cp .env.example .env
npm start
```

### Frontend
```bash
cd frontend
npm install
npm start
```

Open `http://localhost:3000`
